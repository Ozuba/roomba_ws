# roomba_rclgd_starter

Starting point of the rclgd Roomba workshop: a furnished flat, a differential-drive vacuum robot
simulated with Godot physics (`Scenes/roomba/roomba.gd`), the rclgd and rclgd-sensors addons,
and an RViz config. There's no ROS code yet: adding it is the workshop. Follow the tutorial in
`docs/` at the root of the repository.

```bash
ros2 rclgd editor roomba_rclgd_starter     # open in Godot, press F5 to run
```
